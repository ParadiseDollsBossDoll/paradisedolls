# AI Notes README

This folder is the shared project memory for Obsidian, VS Code, and AI-assisted work.

## Files

- `00-ai-project-map.md` - high-level architecture and deployment map.
- `01-feature-index.md` - feature areas and first files to inspect.
- `02-current-state.md` - current production state and active watch points.
- `03-decisions-log.md` - important product and technical decisions.
- `04-change-log.md` - short history of meaningful documentation and code changes.
- `05-ai-rules.md` - rules to follow before and after AI-assisted changes.

## Recommended Obsidian Setup

- Open the full project folder as the vault.
- Use `docs/ai` as the main notes area.
- Enable core plugins:
  - Backlinks
  - Graph view
  - Search
  - Templates
  - Daily notes
  - Outline

## Git Rule

Shared notes in this folder can be committed.

Personal Obsidian layout state, especially `.obsidian/workspace.json`, should stay uncommitted.
