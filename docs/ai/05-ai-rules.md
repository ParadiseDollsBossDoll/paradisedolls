# AI Working Rules

## Brand Transition

- Use Boss Doll Creators for visible website, app, email, and export branding.
- Keep `getrichwithparadisedolls.com` URLs and email addresses, Paradise Dolls social URLs, VPS/database names, and Paradise Dolls legal agreement wording until Kayla supplies confirmed replacements.
- Use `config/brand.php` and the shared brand-logo component instead of duplicating display-brand names or logo paths.

Before making a change:

1. Read 00-ai-project-map.md.
2. Read the relevant feature entry in 01-feature-index.md.
3. Read recent entries in 02-current-state.md and 03-decisions-log.md.
4. Inspect only the listed code files first.
5. Expand investigation only if those files show another dependency.

After a meaningful feature or fix:

1. Update the relevant feature entry.
2. Add a short entry to 03-decisions-log.md if a rule or approach changed.
3. Add a short entry to 04-change-log.md.
4. Update 02-current-state.md when priorities or work-in-progress changes.
